# Проектная работа. Redux-хранилище "Stellar Burger"

## Описание проекта
Крупное React-приложение, реализующее функциональность онлайн-сервиса создания бургеров. Проект содержит работу с Redux, роутингом, авторизацией и WebSocket.

## Основной функционал
* Конструктор бургеров (Drag and Drop).
* Лента заказов (WebSocket).
* Регистрация и авторизация.
* Личный кабинет.
* Защищённые маршруты.
* Работа с API.

## Используемые технологии
* React
* Redux / Redux Toolkit
* React Router
* WebSocket
* Drag and Drop
* Jest + React Testing Library

## Полученные навыки
* Проектирование SPA.
* Организация состояния в Redux.
* Работа с WebSocket.
* Написание тестов.
* Разработка сложной UI-логики.

## Запуск проекта
`npm install`

`npm start`
